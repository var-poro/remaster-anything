# Roadmap

Public release only after phase 3 is done and the directory has at least 10 entries.

## Phase 0: framing
- [ ] Reserve the GitHub repo name and a domain
- [ ] Study Co-op Anything's structure in depth (reference model)
- [ ] Finalise rules: license, no assets, recipes only, credits

## Phase 1: repo skeleton
- [x] README, AGENTS.md, CLAUDE.md, CONTRIBUTING.md, LICENSE
- [x] Skills: triage, research, display, textures, qa, package
- [x] Playbook stubs per phase and per axis
- [x] Directory schema, recipe template, write-up template
- [ ] Review every skill on a real run (phase 3)

## Phase 2: tools (TypeScript, `npx`-installable)
- [ ] MCP server: search directory, detect engine and renderer, detect asset formats, validate entries and recipes, read playbook
- [ ] Capture tool: same viewpoints before/after (saves, console, demos)
- [ ] Fidelity check: downscale-and-compare, palette drift
- [ ] Performance check: frame time capture and comparison
- [ ] `build-directory` script: render DIRECTORY.md from YAML

## Phase 3: pilot, Deus Ex (2000)
- [ ] Triage and identity record
- [ ] Research: every fix, renderer, texture pack, with conflicts and licenses
- [ ] Baseline captures and performance
- [ ] Display and texture passes
- [ ] QA level `automated` reached
- [ ] Recipe + write-up + directory entry
- [ ] Playbook corrected from every friction met

## Phase 4: directory
- [ ] 30 to 50 games with existing remaster work, each with sources and QA level

## Phase 5: launch
- [ ] Site with searchable directory and before/after pages
- [ ] Listings: awesome-ai-game-dev-tools, awesome-game-skill
- [ ] Cross-link with Co-op Anything
- [ ] Discord

## Phase 6: generality
- [ ] Two more games on different engines
- [ ] Open the rendering, audio and port axes
